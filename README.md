# 📘 Vectores en Java

Sitio web educativo y documental sobre **vectores (arrays) en Java**, diseñado para personas que están aprendiendo desde cero.  
El proyecto presenta conceptos clave, ejemplos prácticos y explicaciones claras para entender cómo funciona un vector en Java y cómo se aplican operaciones básicas sobre él.

---

## ✨ Descripción

Este sitio web fue creado como una página educativa para estudiar y comprender el uso de vectores en Java.  
Su objetivo es enseñar de forma visual y ordenada temas como:

- qué es un vector
- cómo se declara y se llena
- cómo recorrerlo con `for`
- cómo buscar valores
- cómo obtener el mayor y el menor
- cómo sumar y calcular el promedio
- cómo identificar múltiplos
- cómo crear un nuevo vector filtrado

La página está pensada para ser clara, moderna y fácil de usar, con una estructura profesional y contenido orientado al aprendizaje.

---

## 🎯 Objetivo del proyecto

Brindar una experiencia educativa que permita a cualquier estudiante:

- comprender la lógica detrás de los vectores
- reconocer estructuras básicas de programación en Java
