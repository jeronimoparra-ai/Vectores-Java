Introducción

¿Qué aprenderás aquí?

Esta guía te lleva paso a paso por un programa completo en Java que manipula un vector de 15 enteros. Comprenderás la lógica, la sintaxis y la utilidad real de cada elemento del programa.

🎯

Propósito de esta guía

Los arreglos (llamados vectores en el ámbito académico) son una de las estructuras de datos fundamentales en programación. Dominarlos te permite trabajar con colecciones de datos, procesar listas y construir algoritmos.


Este sitio explica una clase Java bien estructurada llamada OperacionesVector que realiza operaciones comunes sobre un arreglo de enteros. Cada método se explica en lenguaje sencillo con ejemplos de código anotados.

🚀

Por qué importan los vectores

Las aplicaciones reales almacenan miles de valores: calificaciones de estudiantes, precios de productos, lecturas de sensores. Los vectores te permiten trabajar con muchos valores usando un solo nombre de variable y un bucle, lo que hace tu código conciso y poderoso.

Fundamentos

¿Qué es un vector?

En Java, un vector (o arreglo) es un contenedor que almacena múltiples valores del mismo tipo de dato bajo un único nombre de variable.

Imagina un vector como una fila de buzones numerados en un edificio de apartamentos. Cada buzón (llamado celda) almacena exactamente un valor, y cada uno tiene un número único —llamado índice— que comienza desde cero.

En lugar de crear quince variables separadas (n1, n2, … n15), creas un arreglo y accedes a cualquier valor usando su índice: vector[0], vector[7], etc.

🏠 Analogía: los buzones del edificio

Imagina un edificio con 15 buzones, numerados del 0 al 14. Cada buzón guarda una carta (un entero). El edificio es el arreglo. Los buzones son las celdas. Los números de los buzones son los índices. Las cartas dentro son los valores.

Vector.java
// Declaración y creación int[] vector = new int[15]; // Acceso por índice vector[0] = 42; // primera celda vector[14] = 84; // última celda // Longitud int tamanio = vector.length; // 15
  • int[] Declara un arreglo que almacenará enteros.
  • vector El nombre de la variable. Puedes elegir cualquier identificador Java válido.
  • new int[15] Reserva memoria para exactamente 15 celdas enteras, todas inicializadas en 0.
  • vector[i] Accede a la celda en la posición i. Índices válidos: del 0 al 14.
  • vector.length Propiedad integrada que devuelve el tamaño del arreglo (15).

⚠️ Importante: el índice comienza en 0

El primer elemento es vector[0], no vector[1]. El último elemento de un arreglo de 15 elementos es vector[14]. Intentar acceder a vector[15] lanzará una ArrayIndexOutOfBoundsException.

Vocabulario

Conceptos clave

Cada concepto que se muestra a continuación aparece directamente en el programa Java. Comprenderlos es la base para leer cualquier código Java.

vector / arreglo Estructura de datos

Contenedor de tamaño fijo que almacena valores del mismo tipo.

Un arreglo guarda múltiples valores bajo un mismo nombre de variable. Cada valor ocupa una posición numerada llamada índice. En Java, el tamaño es fijo al momento de la creación. 

int[] notas = new int[5];
índice Acceso

El número de posición de un elemento dentro del arreglo.

Los índices comienzan en 0. En un arreglo de 15 elementos, los índices válidos van del 0 al 14. Usar un índice fuera de rango provoca un error en tiempo de ejecución. 

vector[0]  // primer elemento
vector[14] // último elemento
método POO

Un bloque de código con nombre que realiza una tarea específica.

Los métodos agrupan lógica reutilizable. Se define una vez y se llama muchas veces. Esto evita repetir código y hace los programas más fáciles de leer y mantener. 

public void mostrarVector(int[] v) {
  // lógica de visualización aquí
}
parámetro Entrada

Variable que recibe datos cuando se llama a un método.

Los parámetros se declaran dentro de los paréntesis del método. Actúan como variables locales que contienen los valores pasados por quien lo invoca. Los hacen flexibles y reutilizables. 

// "v" y "valor" son parámetros
boolean buscarValor(int[] v, int valor)
return Salida

Envía un resultado de vuelta desde un método al invocador.

Cuando un método termina su cálculo, return pasa el resultado de regreso. El tipo del valor retornado debe coincidir con el tipo declarado del método. Un método void no retorna nada. 

return suma;   // retorna un int
return true;   // retorna un boolean
for Bucle

Estructura de control que repite un bloque de código un número fijo de veces.

Al trabajar con arreglos, un bucle for visita cada elemento desde el índice 0 hasta length - 1. Elimina el código repetitivo al procesar muchos elementos. 

for (int i = 0; i < v.length; i++) {
  // v[i] es el elemento actual
}
if Condición

Ejecuta un bloque de código solo cuando una condición es verdadera.

La toma de decisiones es esencial en todo programa. if permite al programa elegir un camino según si una condición evalúa a true o false. Se usa para comparaciones, validaciones y filtros. 

if (v[i] > mayor) {
  mayor = v[i];
}
boolean Tipo

Tipo de dato que solo puede valer true o false.

Los booleanos representan decisiones de sí/no. Se usan como banderas para rastrear si algo ocurrió: encontrar un valor, o si se hallaron múltiplos. 

boolean encontro = false;
// se pone true al encontrar
encontro = true;
Scanner Entrada

Clase Java para leer datos ingresados por el usuario desde el teclado.

Scanner es parte de java.util y ofrece métodos como nextInt() para leer enteros, nextDouble() para decimales y next() para cadenas. Conecta el programa con el usuario. 

Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
% (módulo) Operador

Devuelve el resto de una división entera.

Si a % b == 0, entonces a es exactamente divisible por b, es decir, es un múltiplo. Así es como el programa identifica múltiplos de un número dado dentro del arreglo. 

10 % 3 = 1    // no es múltiplo
12 % 3 = 0    // SÍ es múltiplo de 3

Lógica

Flujo del programa

El programa Java sigue una secuencia clara y ordenada de pasos. Así es como cada operación se apoya en la anterior.

1

Crear el vector

Declarar y reservar memoria para un arreglo de enteros de exactamente 15 elementos. Todas las celdas se inicializan en 0 por defecto. 

int[] vector = new int[15];
2

Llenar con valores entre 10 y 100

Usar un bucle for y un Scanner para solicitar al usuario 15 enteros válidos. Una validación asegura que cada valor esté dentro del rango. 

for (int i = 0; i < vector.length; i++)
  vector[i] = sc.nextInt();
3

Mostrar el vector

Llamar a mostrarVector() para imprimir cada elemento con su índice y que el usuario vea el contenido completo del arreglo. 

mostrarVector(vector);
4

Buscar un valor

Pedir al usuario un valor objetivo y llamar a buscarValor(), que recorre el arreglo y devuelve true si el valor existe. 

boolean encontrado = buscarValor(vector, objetivo);
5

Encontrar los valores máximo y mínimo

obtenerMayor() y obtenerMenor() recorren el arreglo una vez, rastreando el valor más alto o más bajo visto hasta el momento. 

int mayor = obtenerMayor(vector);
int menor = obtenerMenor(vector);
6

Calcular suma y promedio

sumarVector() suma todos los elementos. calcularPromedio() divide la suma por el número de elementos, devolviendo un double para mayor precisión. 

int    suma  = sumarVector(vector);
double prom  = calcularPromedio(vector);
7

Mostrar múltiplos de un número dado

Pedir al usuario un divisor y llamar a mostrarMultiplos(). Imprime cada elemento cuyo resto al dividirse por el divisor sea cero. 

mostrarMultiplos(vector, divisor);
8

Construir un vector filtrado (valores > promedio)

crearVectorMayoresPromedio() cuenta los elementos que califican, reserva un nuevo arreglo del tamaño exacto y luego lo llena con los elementos que superan el promedio calculado. 

int[] filtrado =
  crearVectorMayoresPromedio(vector);

Referencia de la API

Clase OperacionesVector – Métodos

Cada método encapsula una operación única y bien definida sobre el arreglo. A continuación encontrarás su firma, propósito, explicación y código anotado.

mostrarVector void

Mostrar todos los elementos

Itera sobre cada celda e imprime su índice y valor, dando al usuario una vista clara del contenido completo del arreglo.

Java
public void mostrarVector(int[] v) { System.out.println("Vector:"); for (int i = 0; i < v.length; i++) { System.out.println( "v[" + i + "] = " + v[i]); } }

Esencial para depurar y verificar que el vector se llenó correctamente antes de ejecutar operaciones adicionales.

buscarValor boolean

Buscar un valor específico

Recorre el arreglo buscando un valor objetivo. Usa una bandera booleana encontro que comienza en false y cambia a true en cuanto se encuentra el valor.

Java
public boolean buscarValor(int[] v, int valor) { boolean encontro = false; for (int i = 0; i < v.length; i++) { if (v[i] == valor) { encontro = true; } } return encontro; }

La búsqueda lineal es fundamental en informática. Este patrón aparece en casi todo programa que necesita verificar si un elemento existe en una colección.

obtenerMayor int

Encontrar el valor máximo

Comienza asumiendo que el primer elemento es el máximo. Luego compara cada elemento siguiente; si es mayor, se convierte en el nuevo máximo.

Java
public int obtenerMayor(int[] v) { int mayor = v[0]; for (int i = 1; i < v.length; i++) { if (v[i] > mayor) { mayor = v[i]; } } return mayor; }

El patrón del "máximo acumulado" se reutiliza en computación: en algoritmos de ordenamiento, análisis de datos y programación competitiva.

obtenerMenor int

Encontrar el valor mínimo

Lógica idéntica a obtenerMayor pero la comparación se invierte: un elemento reemplaza al mínimo actual solo si es menor.

Java
public int obtenerMenor(int[] v) { int menor = v[0]; for (int i = 1; i < v.length; i++) { if (v[i] < menor) { menor = v[i]; } } return menor; }

Encontrar los extremos del rango (mín y máx) es necesario en estadística, validación de datos y normalización antes del análisis.

sumarVector int

Calcular la suma total

Acumula cada elemento en un total creciente comenzando desde cero. El resultado es la suma entera de los 15 valores.

Java
public int sumarVector(int[] v) { int suma = 0; for (int i = 0; i < v.length; i++) { suma += v[i]; } return suma; }

La agregación es una de las operaciones más comunes en el procesamiento de datos. Es el bloque base para promedios, totales y muchas medidas estadísticas.

calcularPromedio double

Calcular el promedio aritmético

Llama internamente a sumarVector y divide por la longitud del arreglo. La conversión a double garantiza que no se pierda la precisión decimal.

Java
public double calcularPromedio(int[] v) { return (double) sumarVector(v) / v.length; }

El promedio se usa para filtrar datos en el método final. Sin la conversión (double), la división entera truncaría la parte decimal.

mostrarMultiplos void

Imprimir elementos que son múltiplos de un número dado

Usa el operador módulo % para evaluar cada elemento. Una bandera booleana encontro rastrea si se encontró al menos un múltiplo.

Java
public void mostrarMultiplos(int[] v, int num) { boolean encontro = false; for (int i = 0; i < v.length; i++) { if (v[i] % num == 0) { System.out.println(v[i]); encontro = true; } } if (!encontro) System.out.println("None found."); }

La prueba de divisibilidad con % se usa en muchos escenarios reales: identificar números pares, separar registros por categoría, implementar paginación.

crearVectorMayoresPromedio int[]

Construir un nuevo arreglo con valores superiores al promedio

Realiza dos recorridos: el primero cuenta cuántos elementos superan el promedio (para reservar el tamaño correcto); el segundo llena el nuevo arreglo usando un índice auxiliar j.

Java
public int[] crearVectorMayoresPromedio(int[] v) { double prom = calcularPromedio(v); int contador = 0; for (int i = 0; i < v.length; i++) if (v[i] > prom) contador++; int[] result = new int[contador]; int j = 0; for (int i = 0; i < v.length; i++) if (v[i] > prom) result[j++] = v[i]; return result; }

Filtrar datos según un umbral calculado (como el promedio) es la base del análisis de datos, sistemas de recomendación y algoritmos de clasificación.

Ejemplos

Recorrido del código

Selecciona un tema para explorar cada patrón de código con una explicación detallada.

Declaración e inicialización del vector
// Paso 1: Declarar el tipo y el nombre int[] vector; // Paso 2: Reservar 15 celdas en memoria vector = new int[15]; // O ambos en una sola línea (más común) int[] vector = new int[15]; // Inmediatamente después, todas las celdas valen 0: // vector[0]=0, vector[1]=0, ..., vector[14]=0

¿Por qué new int[15]?

La palabra clave new le pide a la JVM reservar un bloque contiguo de memoria suficiente para 15 enteros (60 bytes en la mayoría de plataformas, ya que cada int ocupa 4 bytes). Todas las celdas se inicializan en cero por defecto. El tamaño del arreglo es fijo — no puedes agregar ni eliminar elementos después.

Llenar el vector con entrada del usuario (rango 10–100)
Scanner sc = new Scanner(System.in); for (int i = 0; i < vector.length; i++) { int val; do { System.out.print("Enter value " + (i+1) + " (10-100): "); val = sc.nextInt(); } while (val < 10 || val > 100); vector[i] = val; }

El bucle do–while para validar la entrada

Un bucle do–while se ejecuta al menos una vez, ideal para leer entradas: solicitar al usuario, leer el valor, verificar si es válido. Si está fuera del rango (menor de 10 o mayor de 100), el bucle se repite. Solo un valor válido avanza el bucle for externo al siguiente índice.

Algoritmo de búsqueda lineal
boolean encontro = false; // asumir que no se encontró for (int i = 0; i < v.length; i++) { if (v[i] == valor) { encontro = true; // cambiar la bandera } } return encontro; // true si fue encontrado, false si no

El patrón de la bandera booleana

Inicializamos encontro en false ("aún no encontrado"). Dentro del bucle, si algún elemento coincide con el objetivo, lo cambiamos a true. El bucle siempre verifica todos los elementos, lo que garantiza encontrar todas las ocurrencias, no solo la primera. Finalmente, return encontro le dice al invocador el resultado.

Encontrar los valores máximo y mínimo
// Máximo int mayor = v[0]; // comenzar con el primer elemento for (int i = 1; i < v.length; i++) { if (v[i] > mayor) { mayor = v[i]; // actualizar si es mayor } } // Mínimo (solo cambia la comparación) int menor = v[0]; for (int i = 1; i < v.length; i++) { if (v[i] < menor) { menor = v[i]; // actualizar si es menor } }

Máximo acumulado / Mínimo acumulado

Ambos algoritmos comienzan asumiendo que la respuesta es el primer elemento. El bucle luego parte del índice 1 (porque el índice 0 ya se usó como suposición inicial). En cada iteración, si el elemento actual es más extremo que la respuesta actual, ésta se actualiza. Al terminar el bucle, mayor / menor contiene el extremo global.

Acumular la suma de todos los elementos
int suma = 0; // el acumulador comienza en cero for (int i = 0; i < v.length; i++) { suma += v[i]; // equivale a: suma = suma + v[i] } return suma;

El patrón acumulador

suma comienza en 0. En cada iteración, el valor del elemento actual se añade al total acumulado. += es la forma abreviada de suma = suma + v[i]. Al finalizar el bucle, suma contiene el total completo de los 15 valores.

Calcular el promedio aritmético
// Sin conversión: la división entera trunca el decimal int malo = sumarVector(v) / v.length; // ❌ pierde .5, .3, etc. // Con conversión: promueve el numerador a double antes de dividir double promedio = (double) sumarVector(v) / v.length; // ✅ return promedio;

¿Por qué convertir a double?

En Java, dividir dos enteros siempre da un resultado entero. Si la suma es 825 y la longitud es 15, 825 / 15 = 55 — exacto en este caso. Pero 826 / 15 = 55 (no 55,066…). La conversión (double) transforma la suma en un número de punto flotante antes de dividir, preservando la precisión decimal para el paso de filtrado.

Detectar y mostrar múltiplos
boolean encontro = false; for (int i = 0; i < v.length; i++) { if (v[i] % num == 0) { // sin resto = múltiplo System.out.println(v[i]); encontro = true; } } if (!encontro) { System.out.println("No multiples found."); }

El operador módulo y la bandera encontro

v[i] % num == 0 es verdadero cuando el elemento se divide exactamente por num sin resto — la definición de múltiplo. La bandera encontro cumple un propósito secundario: si el bucle termina sin encontrar ningún múltiplo, el programa imprime un mensaje útil en lugar de producir una salida vacía.

Algoritmo de dos recorridos para construir un arreglo filtrado
double prom = calcularPromedio(v); // Recorrido 1: contar cuántos elementos superan el promedio int contador = 0; for (int i = 0; i < v.length; i++) if (v[i] > prom) contador++; // Reservar el arreglo resultado con el tamaño exacto necesario int[] result = new int[contador]; // Recorrido 2: llenar el arreglo resultado int j = 0; // índice para result[] for (int i = 0; i < v.length; i++) { if (v[i] > prom) { result[j] = v[i]; j++; } } return result;

¿Por qué dos recorridos?

Los arreglos Java tienen tamaño fijo: debes conocer el tamaño antes de crearlos. El primer recorrido cuenta los elementos que califican (contador). Ese conteo se usa como tamaño del nuevo arreglo. El segundo recorrido lo llena, usando el índice j que avanza independientemente de i — i recorre todos los elementos; j solo avanza cuando un elemento es copiado efectivamente.

Análisis profundo

Análisis del código

Cada construcción usada en este programa tiene un rol específico. Aquí encontrarás una explicación detallada de las más importantes.

🔁
bucle for

El bucle for se usa en todos los métodos porque toda operación sobre un vector requiere visitar cada elemento. El bucle inicializa i = 0, verifica i < v.length e incrementa i++ después de cada iteración. Esto garantiza exactamente v.length repeticiones — ni más, ni menos.

❓
condición if

if hace que el programa "decida" en tiempo de ejecución. Evalúa una expresión booleana y solo ejecuta su cuerpo cuando el resultado es true. En este programa, if verifica igualdad (==), mayor-que (>), menor-que (<) y divisibilidad (% == 0).

↩️
return

return termina la ejecución del método y envía un valor de vuelta al invocador. Sin él, quien llama al método no puede recibir el resultado del cálculo. Los métodos declarados como void usan return; (sin valor) o no tienen return en absoluto.

➗
operador %

El operador módulo (o resto) devuelve lo que sobra después de la división entera. 18 % 5 = 3 porque 18 ÷ 5 = 3 con resto 3. Cuando el resultado es exactamente 0, el operando izquierdo es múltiplo del derecho. Este es el núcleo de mostrarMultiplos.

🚩
encontro (bandera booleana)

encontro comienza en false antes del bucle. Dentro del bucle, si la condición se cumple, se establece en true. Después del bucle, leer encontro indica si al menos un elemento coincidente fue encontrado. Se usa tanto en los métodos de búsqueda como en el de múltiplos.

🔢
contador (conteo)

contador comienza en 0 e incrementa (contador++) cada vez que un elemento satisface la condición de filtro. Su valor final le dice al programa exactamente qué tan grande debe ser el nuevo arreglo resultado, permitiendo una reserva de memoria precisa sin desperdicio.

📍
variable de índice i

i es el contador del bucle que actúa como posición actual dentro del arreglo. Comienza en 0 (la primera celda) y sube hasta v.length - 1 (la última celda). Cada vez que el cuerpo del bucle se ejecuta, v[i] hace referencia al elemento en la posición actual.

📝
índice auxiliar j

j es la "posición de escritura" en el arreglo resultado. Mientras i itera sobre todos los elementos del arreglo fuente, j solo avanza cuando un elemento pasa el filtro. Esto evita "huecos" (celdas vacías) en el arreglo resultado y mantiene los datos filtrados contiguos.

Ayuda

Preguntas frecuentes

Respuestas a las dudas más comunes que surgen al estudiar este programa.

¿Qué es exactamente un vector?

Un vector es otro nombre para un arreglo unidimensional. Es una lista numerada de valores del mismo tipo, almacenados juntos en memoria. En Java se declara como int[] v = new int[n];.

¿Por qué el bucle for se repite exactamente 15 veces?

Porque la condición i < v.length se verifica antes de cada iteración. Como v.length es 15 e i comienza en 0, el bucle se ejecuta para i = 0, 1, 2, …, 14 — exactamente 15 veces.

¿Por qué el índice empieza en 0 y no en 1?

Esta es una convención de Java (y de la familia C). El índice representa un desplazamiento desde el inicio del arreglo. El primer elemento está a 0 posiciones del comienzo, así que su índice es 0. Así funciona la mayoría de los lenguajes de programación.

¿Cómo evito un ArrayIndexOutOfBoundsException?

Usa siempre i < v.length (no i <= v.length) como condición del bucle. Recuerda que el último índice válido es v.length - 1. Nunca pongas el tamaño del arreglo como constante; usa v.length para que el código se adapte si el tamaño cambia.

¿Cómo leo y entiendo la salida?

Cada System.out.println() imprime una línea. Para la visualización del vector, verás líneas como v[0] = 42, que significa "el elemento en la posición 0 tiene el valor 42". La búsqueda retorna true o false. El promedio es un número decimal.

¿Por qué hay dos bucles en crearVectorMayoresPromedio?

El primer bucle cuenta cuántos elementos pasan el filtro para poder crear un arreglo con el tamaño correcto. Java requiere conocer el tamaño al momento de crearlo. El segundo bucle llena ese arreglo con los elementos que califican.

¿Qué pasa si no se encuentran múltiplos?

La bandera booleana encontro permanece en false. Después del bucle, if (!encontro) captura este caso e imprime un mensaje como "No multiples found." — así la salida nunca está vacía ni resulta confusa.

¿Qué hace (double) en calcularPromedio?

Es una conversión de tipo (cast). Sin ella, Java realiza división entera y descarta la parte fraccionaria. Con la conversión, la suma se trata temporalmente como un double antes de dividir, preservando la precisión decimal.

Glosario

Definiciones rápidas de cada término técnico utilizado en esta guía.

vector / arreglo

Colección ordenada de tamaño fijo de valores del mismo tipo de dato, a la que se accede mediante un índice numérico.

índice

Entero que comienza en cero e identifica la posición de un elemento dentro de un arreglo.

método

Bloque de código con nombre, reutilizable, que realiza una tarea específica y puede devolver un resultado.

parámetro

Variable declarada en la firma de un método que recibe un valor cuando el método es invocado.

return

Palabra clave de Java que termina la ejecución de un método y envía un valor de vuelta al invocador.

bucle

Estructura de control que repite un bloque de código mientras una condición sea verdadera.

condición

Expresión booleana evaluada en tiempo de ejecución para decidir si un bloque de código se ejecuta.

módulo (%)

El operador resto. a % b devuelve lo que sobra después de dividir a entre b.

boolean

Tipo de dato que solo puede ser true o false. Se usa para banderas y condiciones.

Scanner

Clase de la biblioteca estándar de Java (java.util.Scanner) que lee entrada desde el teclado u otras fuentes.

contador

Variable inicializada en cero que se incrementa cada vez que ocurre un evento específico dentro de un bucle.

filtrado

El proceso de crear una nueva colección que incluye solo los elementos que satisfacen una condición dada.
