Fundamentals

What is a Vector?

In Java, a vector (or array) is a container that stores multiple values of the same data type under a single variable name.

Think of a vector as a row of numbered mailboxes at an apartment building. Each mailbox (called a cell) holds exactly one value, and each has a unique number — called an index — starting from zero.

Instead of creating fifteen separate variables (n1, n2, … n15), you create one array and access any value using its index: vector[0], vector[7], etc.

🏠 Analogy: the apartment mailboxes

Imagine a building with 15 mailboxes, numbered 0 to 14. Each mailbox stores a single letter (an integer). The building is the array. The mailboxes are the cells. The mailbox numbers are the indices. The letters inside are the values.

Vector.java
// Declaration and creation int[] vector = new int[15]; // Access by index vector[0] = 42; // first cell vector[14] = 84; // last cell // Length int size = vector.length; // 15
  • int[] Declares an array that will hold integers.
  • vector The name of the variable. You can choose any valid Java identifier.
  • new int[15] Allocates memory for exactly 15 integer cells, all initialized to 0.
  • vector[i] Accesses the cell at position i. Valid indices: 0 to 14.
  • vector.length A built-in property that returns the size of the array (15).

⚠️ Important: Index starts at 0

The first element is vector[0], not vector[1]. The last element of a 15-element array is vector[14]. Trying to access vector[15] will throw an ArrayIndexOutOfBoundsException.

Vocabulary

Key Concepts

Every concept below appears directly in the Java program. Understanding them is the foundation for reading any Java code.

vector / array Data Structure

A fixed-size container holding values of the same type.

An array stores multiple values under one variable name. Each value occupies a numbered slot called an index. In Java, the size is fixed at creation time. 

int[] notas = new int[5];
index Access

The position number of an element inside the array.

Indices start at 0. In an array of 15 elements, valid indices go from 0 to 14. Using an out-of-range index causes a runtime error. 

vector[0]  // first element
vector[14] // last element
method OOP

A named block of code that performs a specific task.

Methods group reusable logic. You define a method once and call it many times. This avoids repeating the same code and makes programs easier to read and maintain. 

public void mostrarVector(int[] v) {
  // display logic here
}
parameter Input

A variable that receives data when a method is called.

Parameters are declared inside the method's parentheses. They act as local variables that hold the values passed by the caller. They make methods flexible and reusable. 

// "v" and "valor" are parameters
boolean buscarValor(int[] v, int valor)
return Output

Sends a result back from a method to the caller.

When a method finishes its calculation, return passes the result back. The type of the returned value must match the method's declared return type. A void method returns nothing. 

return suma;   // returns an int
return true;   // returns a boolean
for Loop

A control structure that repeats a block of code a set number of times.

When working with arrays, a for loop visits every element from index 0 to length - 1. It eliminates repetitive code when processing many elements. 

for (int i = 0; i < v.length; i++) {
  // v[i] is the current element
}
if Condition

Executes a block of code only when a condition is true.

Decision-making is essential in every program. if lets the program choose a path based on whether a condition evaluates to true or false. It is used for comparisons, validations, and filtering. 

if (v[i] > mayor) {
  mayor = v[i];
}
boolean Type

A data type that holds only true or false.

Booleans represent yes/no decisions. They are used as flags to track whether something happened — like finding a value, or whether any multiples were found. 

boolean encontro = false;
// set to true when found
encontro = true;
Scanner Input

A Java class for reading user input from the keyboard.

Scanner is part of java.util and provides methods like nextInt() to read integers, nextDouble() for decimals, and next() for strings. It connects the program to the user. 

Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
% (modulo) Operator

Returns the remainder of an integer division.

If a % b == 0, then a is exactly divisible by b — making it a multiple. This is how the program identifies multiples of a given number inside the array. 

10 % 3 = 1    // not a multiple
12 % 3 = 0    // IS a multiple of 3

API Reference

Class OperacionesVector – Methods

Each method encapsulates a single, well-defined operation on the array. Below you will find its signature, purpose, explanation, and annotated code.

mostrarVector void

Display all elements

Iterates over every cell and prints its index and value, giving the user a clear view of the entire array contents.

Java
public void mostrarVector(int[] v) { System.out.println("Vector:"); for (int i = 0; i < v.length; i++) { System.out.println( "v[" + i + "] = " + v[i]); } }

Essential for debugging and verifying that the vector was filled correctly before running further operations.

buscarValor boolean

Search for a specific value

Traverses the array looking for a target value. Uses a boolean flag encontro that starts as false and flips to true as soon as the value is found.

Java
public boolean buscarValor(int[] v, int valor) { boolean encontro = false; for (int i = 0; i < v.length; i++) { if (v[i] == valor) { encontro = true; } } return encontro; }

Linear search is fundamental in computer science. This pattern appears in nearly every program that needs to check membership in a collection.

obtenerMayor int

Find the maximum value

Starts by assuming the first element is the maximum. Then compares each subsequent element; if it is larger, it becomes the new maximum.

Java
public int obtenerMayor(int[] v) { int mayor = v[0]; for (int i = 1; i < v.length; i++) { if (v[i] > mayor) { mayor = v[i]; } } return mayor; }

The "running maximum" pattern is reused throughout computing — in sorting algorithms, data analysis, and competitive programming.

obtenerMenor int

Find the minimum value

Identical logic to obtenerMayor but the comparison is reversed: an element replaces the current minimum only if it is smaller.

Java
public int obtenerMenor(int[] v) { int menor = v[0]; for (int i = 1; i < v.length; i++) { if (v[i] < menor) { menor = v[i]; } } return menor; }

Finding range extremes (min and max) is required in statistics, data validation, and normalizing data before analysis.

sumarVector int

Compute the total sum

Accumulates every element into a running total starting at zero. The result is an integer sum of all 15 values.

Java
public int sumarVector(int[] v) { int suma = 0; for (int i = 0; i < v.length; i++) { suma += v[i]; } return suma; }

Aggregation is one of the most common operations in data processing. This is the building block for averages, totals, and many statistical measures.

calcularPromedio double

Calculate the arithmetic average

Calls sumarVector internally, then divides by the array length. The cast to double ensures decimal precision is not lost.

Java
public double calcularPromedio(int[] v) { return (double) sumarVector(v) / v.length; }

The average is used to filter the data in the final method. Without the (double) cast, integer division would truncate the decimal part.

mostrarMultiplos void

Print elements that are multiples of a given number

Uses the modulo operator % to test each element. A boolean flag encontro tracks whether at least one multiple was found.

Java
public void mostrarMultiplos(int[] v, int num) { boolean encontro = false; for (int i = 0; i < v.length; i++) { if (v[i] % num == 0) { System.out.println(v[i]); encontro = true; } } if (!encontro) System.out.println("None found."); }

Divisibility testing with % is used in many real scenarios: identifying even numbers, separating records by category, implementing pagination.

crearVectorMayoresPromedio int[]

Build a new array with values above the average

Makes two passes: the first counts how many elements exceed the average (to allocate correctly), the second fills the new array using an index variable j.

Java
public int[] crearVectorMayoresPromedio(int[] v) { double prom = calcularPromedio(v); int contador = 0; for (int i = 0; i < v.length; i++) if (v[i] > prom) contador++; int[] result = new int[contador]; int j = 0; for (int i = 0; i < v.length; i++) if (v[i] > prom) result[j++] = v[i]; return result; }

Filtering data based on a computed threshold (like an average) is the basis of data analysis, recommendation systems, and classification algorithms.

Examples

Code Walkthrough

Select a topic below to explore each code pattern with a detailed explanation.

Vector declaration and initialization
// Step 1: Declare the type and name int[] vector; // Step 2: Allocate 15 cells in memory vector = new int[15]; // Or both in one line (most common) int[] vector = new int[15]; // Immediately after, all cells equal 0: // vector[0]=0, vector[1]=0, ..., vector[14]=0

Why new int[15]?

The new keyword asks the JVM to reserve a contiguous block of memory large enough for 15 integers (60 bytes on most platforms, since each int is 4 bytes). All cells are zero-initialized by default. The array's size is fixed — you cannot add or remove elements later.

Filling the vector with user input (range 10–100)
Scanner sc = new Scanner(System.in); for (int i = 0; i < vector.length; i++) { int val; do { System.out.print("Enter value " + (i+1) + " (10-100): "); val = sc.nextInt(); } while (val < 10 || val > 100); vector[i] = val; }

The do–while for input validation

A do–while loop runs at least once, which is ideal for reading input: prompt the user, read the value, check if it is valid. If it is out of range (below 10 or above 100), the loop repeats. Only a valid value advances the outer for loop to the next index.

Linear search algorithm
boolean encontro = false; // assume not found for (int i = 0; i < v.length; i++) { if (v[i] == valor) { encontro = true; // flip the flag } } return encontro; // true if found, false otherwise

The boolean flag pattern

We initialise encontro as false ("not found yet"). Inside the loop, if any element matches the target, we flip it to true. The loop always checks every element — this ensures we find all occurrences, not just the first. Finally, return encontro tells the caller the result.

Finding maximum and minimum values
// Maximum int mayor = v[0]; // start with first element for (int i = 1; i < v.length; i++) { if (v[i] > mayor) { mayor = v[i]; // update if larger } } // Minimum (only the comparison flips) int menor = v[0]; for (int i = 1; i < v.length; i++) { if (v[i] < menor) { menor = v[i]; // update if smaller } }

Running maximum / running minimum

Both algorithms start by assuming the answer is the first element. The loop then starts from index 1 (because index 0 was already used as the initial assumption). Each iteration, if the current element is more extreme than the current answer, the answer is updated. After the loop, mayor / menor holds the global extreme.

Accumulating the sum of all elements
int suma = 0; // accumulator starts at zero for (int i = 0; i < v.length; i++) { suma += v[i]; // same as: suma = suma + v[i] } return suma;

The accumulator pattern

suma starts at 0. On every iteration, the current element's value is added to the running total. += is shorthand for suma = suma + v[i]. After the loop, suma holds the complete total of all 15 values.

Computing the arithmetic average
// Without cast: integer division truncates the decimal int bad = sumarVector(v) / v.length; // ❌ loses .5, .3, etc. // With cast: promotes numerator to double before dividing double promedio = (double) sumarVector(v) / v.length; // ✅ return promedio;

Why cast to double?

In Java, dividing two integers always gives an integer result. If the sum is 825 and the length is 15, 825 / 15 = 55 — exact in this case. But 826 / 15 = 55 (not 55.066…). The (double) cast converts the sum to a floating-point number before the division, preserving decimal precision for the filter step.

Detecting and displaying multiples
boolean encontro = false; for (int i = 0; i < v.length; i++) { if (v[i] % num == 0) { // no remainder = multiple System.out.println(v[i]); encontro = true; } } if (!encontro) { System.out.println("No multiples found."); }

The modulo operator and the encontro flag

v[i] % num == 0 is true when the element divides exactly by num with no remainder — the definition of a multiple. The encontro flag serves a secondary purpose: if the loop finishes and no multiple was found, the program prints a helpful message instead of producing empty output.

Two-pass algorithm to build a filtered array
double prom = calcularPromedio(v); // Pass 1: count how many elements exceed the average int contador = 0; for (int i = 0; i < v.length; i++) if (v[i] > prom) contador++; // Allocate the result array with the exact needed size int[] result = new int[contador]; // Pass 2: fill the result array int j = 0; // index for result[] for (int i = 0; i < v.length; i++) { if (v[i] > prom) { result[j] = v[i]; j++; } } return result;

Why two passes?

Java arrays have a fixed size: you must know the size before you create them. The first pass counts qualifying elements (contador). That count is used as the size for the new array. The second pass fills it, using index j which increments independently of i — i moves through every element; j only advances when an element is actually copied.

Deep Dive

Code Analysis

Every construct used in this program has a specific role. Here is a focused explanation of the most important ones.

🔁
for loop

The for loop is used in every method because every operation on a vector requires visiting each element. The loop initialises i = 0, checks i < v.length, and increments i++ after each iteration. This guarantees exactly v.length repetitions — no more, no less.

❓
if condition

if makes the program "decide" at runtime. It evaluates a boolean expression and only executes its body when the result is true. In this program, if checks for equality (==), greater-than (>), less-than (<), and divisibility (% == 0).

↩️
return

return ends the method's execution and sends a value back to the caller. Without it, the caller cannot receive the result of the computation. Methods that declare void use return; (no value) or no return at all.

➗
% operator

The modulo (or remainder) operator returns what is left over after integer division. 18 % 5 = 3 because 18 ÷ 5 = 3 remainder 3. When the result is exactly 0, the left operand is a multiple of the right. This is the core of mostrarMultiplos.

🚩
encontro (boolean flag)

encontro starts as false before the loop. Inside the loop, if the condition is met, it is set to true. After the loop, reading encontro tells you whether at least one matching element was found. It is used in both the search and multiples methods.

🔢
contador (counter)

contador starts at 0 and increments (contador++) each time an element satisfies the filter condition. Its final value tells the program exactly how large the new result array needs to be, enabling precise memory allocation without waste.

📍
index variable i

i is the loop counter that acts as the current position inside the array. It starts at 0 (the first cell) and goes up to v.length - 1 (the last cell). Every time the loop body runs, v[i] refers to the element at the current position.

📝
auxiliary index j

j is the "write position" in the result array. While i iterates over every element of the source array, j only advances when an element passes the filter test. This prevents "holes" (empty cells) in the result array and keeps the filtered data contiguous.

Help

Common Questions

Answers to questions beginners frequently ask when studying this program.

What exactly is a vector?

A vector is another name for a one-dimensional array. It is a numbered list of values of the same type, stored together in memory. In Java, it is declared as int[] v = new int[n];.

Why does the for loop repeat exactly 15 times?

Because the condition i < v.length is checked before every iteration. Since v.length is 15 and i starts at 0, the loop runs for i = 0, 1, 2, …, 14 — exactly 15 times.

Why does the index start at 0, not 1?

This is a Java (and C family) convention. The index represents an offset from the start of the array. The first element is 0 offsets away from the beginning, so its index is 0. This is how most programming languages work.

How do I avoid an ArrayIndexOutOfBoundsException?

Always use i < v.length (not i <= v.length) as your loop condition. Remember the last valid index is v.length - 1. Never hard-code the array size; use v.length so the code adapts if the size changes.

How do I read and understand the output?

Each System.out.println() prints one line. For the vector display, you will see lines like v[0] = 42, meaning "the element at position 0 has the value 42". The search returns true or false. The average is a decimal number.

Why are there two loops in crearVectorMayoresPromedio?

The first loop counts how many elements pass the filter so a correctly-sized array can be created. Java requires the size at creation time. The second loop fills that array with the qualifying elements.

What happens if no multiples are found?

The boolean flag encontro stays false. After the loop, if (!encontro) catches this case and prints a message like "No multiples found." — so the output is never empty or confusing.

What does (double) do in calcularPromedio?

It is a type cast. Without it, Java performs integer division and discards the fractional part. With the cast, the sum is temporarily treated as a double before dividing, preserving decimal accuracy.

Glossary

Quick definitions for every technical term used in this guide.

vector / array

A fixed-size, ordered collection of values of the same data type, accessed by numeric index.

index

A zero-based integer that identifies the position of an element within an array.

method

A named, reusable block of code that performs a specific task and may return a result.

parameter

A variable declared in a method's signature that receives a value when the method is called.

return

A Java keyword that ends a method's execution and sends a value back to the caller.

loop

A control structure that repeats a block of code while a condition holds true.

condition

A boolean expression evaluated at runtime to decide whether a block of code executes.

modulo (%)

The remainder operator. a % b returns what is left after dividing a by b.

boolean

A data type that holds only true or false. Used for flags and conditions.

Scanner

A Java standard library class (java.util.Scanner) that reads input from the keyboard or other sources.

counter

A variable initialised to zero that is incremented each time a specific event occurs in a loop.

filtering

The process of creating a new collection that includes only elements that satisfy a given condition.
